# Pronunciation probe results

Generated by `scripts/probe-pronunciation.js` against the live 302.ai endpoint
(`speech-2.8-turbo`, voice `Friendly_Person`), with each clip transcribed by
Gemini using a schema that forces a phonetic self-report rather than a tidied
transcript.

This is the evidence behind `PRONUNCIATION_DEFAULTS` in `tts-config.json`.
Re-run the probe before changing that list.

**Caveat on method.** The transcriber is a screening tool, not ground truth: it
will occasionally normalise a spoken phrase back into its abbreviation. One case
here ("good game easy" reported as "G.G. E.Z.") was re-checked with a targeted
prompt and confirmed to be a transcription artifact, not a synthesis problem.
Clips are saved so any disputed row can be settled by listening.

## Headline findings

1. **`pronunciation_dict` is case-sensitive.** With `["lfg/lets go"]` loaded,
   the input `lfg LFG Lfg` came back as *"Let's go. LFG. LFG."* — only the
   lowercase occurrence was substituted. Chat casing is arbitrary, so the API
   parameter is unusable for this without enumerating every casing variant.
   This is why the dictionary is applied as a local, case-insensitive rewrite
   before the request is built.
2. **`lol` already reads as "el oh el"** and is deliberately absent from the
   dictionary. Verified with a targeted yes/no check on the sound across all
   four of `lol`, `LOL`, `"lol that's funny"` and `"LOL that's funny"` — every
   one spells the letters out individually. (The first pass reported the
   uppercase case as a single syllable; that was the same normalisation
   artifact described above, not a real casing difference.) The dictionary has
   no entry shorter than two characters and none that `lol` contains, so
   nothing can collide with it. `tests/unit/lib/textRewrite.test.js` asserts
   `lol` and `lollipop` pass through the full rule set byte-identical.
3. **MiniMax spells almost everything out** rather than mangling it. Only
   8 of the 92 candidates come out as nonsense. The dictionary's
   main job is therefore naturalness, not repair.
4. **No entry cap was hit** at 101 entries, and no `base_resp` error was
   returned.

## Matching semantics probes

Is matching case sensitive? A lowercase key against three casings.

Input: `lfg LFG Lfg`  
Heard: **Let's go. LFG. LFG.**

### boundary

Word boundary or substring? "angle" and "mingle" contain "ngl".

Input: `NGL angle ANGLE mingle`  
Heard: **Not going to lie, angle angle mingle**

### lol-hazard
